# Profitscape

Простой скрипт `hello.py`, который выводит текущую дату и время по Астане
и сообщение «Profitscape запущен».

## Требования

- Python 3.9 или новее (проверить версию: `python3 --version`).

## Запуск

1. Откройте терминал в папке проекта.
2. Выполните команду:

   ```bash
   python3 hello.py
   ```

   На Windows используйте:

   ```bash
   python hello.py
   ```

## Пример вывода

```
Дата и время в Астане: 03.11.2026 14:00:00 (UTC+0500)
Profitscape запущен
```

## Примечание о часовом поясе

С 1 марта 2024 года Астана (как и весь Казахстан) живёт по времени UTC+5.
Скрипт использует часовой пояс `Asia/Almaty` из системной базы часовых поясов.
Если она недоступна (например, на Windows без пакета `tzdata`), скрипт
автоматически использует фиксированное смещение UTC+5. При желании можно
установить базу часовых поясов:

```bash
pip install tzdata
```
